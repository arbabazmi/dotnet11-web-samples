# .NET 11 Web Samples

Three small ASP.NET Core 11 projects exploring what is new on the web side of .NET 11. All data is synthetic.

| Project | Folder | Status |
| --- | --- | --- |
| 1. Fee calculator API with C# 15 union types | `src/FeeCalc.Api` | Done |
| 2. MCP server + Blazor AI chat | `src/CommissionMcp.*` | Server and Blazor chat built; tested headless with an offline demo model (no real model or browser run yet) |
| 3. Native AOT cold-start benchmark | `src/Aot.Bench` | Local Docker benchmark done |

SDK is pinned in `global.json` (.NET 11.0.100).
