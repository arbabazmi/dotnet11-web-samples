# CommissionMcp.Server: Project 2, part 1

An MCP (Model Context Protocol) server over **synthetic** advisor commission data. Created from the .NET 11 SDK template
(`dotnet new mcpserver -t remote`), HTTP transport, **stateless** mode.

Versions: .NET SDK 11.0.100, `net11.0`, `ModelContextProtocol.AspNetCore` 2.1.0 (what the template pins; the spec said "v2.0").

## Tools

| Tool | Kind | What it does |
| --- | --- | --- |
| `get_advisor_summary(advisorId)` | read-only | Profile, year-to-date commission, last closed month, open-month payout |
| `get_statement(advisorId, month)` | read-only | Line items, gross commission, adjustments and net payout for `yyyy-MM` |
| `adjust_payout(advisorId, amount, reason)` | **write** | Adds an adjustment to the open month (2026-11) |

The tools carry MCP annotations (`readOnlyHint`, `destructiveHint`), so a client can decide which calls need human approval
without hard-coding tool names. `adjust_payout` is the only tool that changes data.

Rules enforced by the server: amount is non-zero, at most 5,000 in either direction, at most two decimals; reason has at
least 5 characters; unknown advisors and months return a readable tool error (`isError: true`), not a server fault.

## Synthetic data

Five fictional advisors (`A-101` to `A-105`), closed months `2026-07` to `2026-10`, open month `2026-11`. Statement lines are
generated by a fixed algorithm, so the numbers are identical on every run. The store is in memory: restarting the server
discards adjustments.

## Run

```powershell
dotnet run --project src/CommissionMcp.Server --urls http://localhost:5290
```

The MCP endpoint is `http://localhost:5290/mcp`. Any MCP client can connect; the tests use the official C# client. The
MCP Inspector should work too (not yet tried for this project):

```powershell
npx @modelcontextprotocol/inspector
# transport: Streamable HTTP, URL: http://localhost:5290/mcp
```

## Test

```powershell
dotnet test tests/CommissionMcp.Server.Tests
```

21 tests: store rules and boundaries, plus calls through the official MCP client against the real endpoint (tool list,
read-only hints, each tool, tool errors, and an adjustment that shows up in the summary).
